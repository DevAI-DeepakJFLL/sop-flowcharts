# SOP Flowcharts

This repository contains **Standard Operating Procedure (SOP) flowchart files** created using [draw.io](https://www.drawio.com/).

The flowcharts are maintained in this repository for version control, reference, and collaboration.

## How to Open and View a Flowchart

You can view the `.drawio` files using the online **diagrams.net (draw.io)** application.

### Steps

1. Go to **https://app.diagrams.net/**
2. Select **Device** when asked where to save or open files.
3. Click **Open Existing Diagram**.
4. Select **Open from Device**.
5. Navigate to the location where you downloaded or cloned this repository.
6. Select the `.drawio` file you want to view.
7. The flowchart will open in diagrams.net.

### Alternative: Open a File Directly

You can also drag and drop a `.drawio` file from your computer directly into the diagrams.net window.

> **Note:** The `.drawio` files contain the editable flowchart diagrams. Avoid modifying or deleting files unless you intend to update the corresponding SOP flowchart.
